# Activity Manager - Laravel

Project Proyek 3 Modul 3 menggunakan Laravel untuk membuat aplikasi manajemen kegiatan.

Project ini menerapkan:
- CRUD kegiatan
- Resource Controller
- Route Model Binding
- Form Request untuk validasi
- Activity Service untuk business logic
- Validasi transisi status
- SQLite sebagai database

## Teknologi

- Laravel 13
- PHP 8.3+
- SQLite
- Composer
- Laravel Pint
